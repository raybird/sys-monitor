規劃日期：2026-10-05。規模、風險、首要驗證與檔案邊界以 [README](README.md) 為唯一來源。

## 設計與使用方式

依 START／STOP 界定 session，依 START／ROTATE 收集取樣檔並從最新有效取樣向前回退。非正常關機新增 UNCLEAN，歷史 FREEZE 仍可回顧但不宣稱已確認原因。回顧窗口以 last_sample 為終點並涵蓋同 session 的相鄰輪替檔；沒有 last_sample 的歷史事件沿用事件時間。
